# 巧巴達 Ciabatta

`BV-004` · Adria, Italy · 拖鞋的形狀

## L1 命名 #命名/商業

1982 年，義大利 Adria。發明人 Arnaldo Cavallari，本業是**拉力賽車手**，家裡開麵粉廠。

動機不高尚：他受不了法國長棍在義大利三明治市場橫著走，決定做一個出來對打。找了 Francesco
Favarone 和 Cremonesi 兩位師傅，在自家磨坊試了好幾週。1982 年 9 月，註冊為 "ciabatta italia"；
到 1999 年，已經授權給 11 個國家的烘焙業者用這個名字。原名 ciabatta polesana，取自他住的
Polesine 地區。

**法棍靠法律、布里歐靠故事、潘娜朵尼兩個都要，它靠註冊商標。** 而且它比布里歐那個假故事還年輕，
只有 40 幾歲，卻已經被當成「義大利傳統麵包」在賣。

## L2 座標

範圍寬度 ＝ 模糊空間。

| 軸 | 程度 | 範圍 | 註解 |
|---|---|---|---|
| 含水量 | #含水量/極高 | `75–85` | 定義性特徵，80% 以上才會有那種氣孔 |
| 豐富度 | #豐富度/零 | `0–5` | 幾乎瘦麵團，但沒被法律釘死——模糊空間比法棍寬，只是實務上沒人加 |
| 麥種結構 | #麥種/高 | `90–100` | 高筋白麵粉 |
| 發酵時間 | #發酵/中高 | `40–55` | 傳統用 biga（義式硬種），比直接法長 |
| 麵筋擴展 | #麵筋/中高 | `55–75` | 靠摺疊做出來的，撐得起 80% 含水的麵團（見 issue #17） |

## L4 勾稽

```
#含水量/極高 -- 麵團鬆到幾乎流動 -- 大而不規則的氣孔
              （這條不是必然：整形跟不上，氣孔一樣塌掉）

#含水量/極高 -- 太濕，手揉根本抓不住 -- 只能靠摺疊與時間

biga -- 含水低，麵筋先在硬種裡練過 -- 撐得住後面的高水
              （義式硬種：含水 50–60%，比 poolish 硬）

#含水量/極高 -- 值沒變，代價變了：同樣的麵筋，手要更穩 -- 整形技術
              ※ 跟免揉麵包正好相反。那張用時間付，這張用手付

巧巴達 -- 都是低油高水，差別只在你有沒有耐心整形 -- 法棍
```

## L3 結果

大而不規則的氣孔、殼薄脆但比法棍軟、麵包心濕潤有嚼勁、味道偏淡（沒有油也沒有長發酵的酸）。
名字 ciabatta 是義大利文的「拖鞋」，因為它扁塌的樣子。

## L5 手

```
! 手不能多碰，一碰氣就掉了
! 分割用切的，不能用扯的
! 高水麵團靠摺疊而不是揉 —— 什麼時候該摺、摺幾次是手感
```
