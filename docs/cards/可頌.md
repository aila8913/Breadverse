# 可頌 Croissant

`BV-007` · France · 形狀沒有規定，但大家都以為有

## L1 命名 #命名/傳說

流傳很廣的說法：法國規定用瑪琪琳做的可頌要彎成月牙形，全奶油做的要做成直的，所以看形狀就能
分辨用料。

**這是假的。** 法國麵包糕餅業全國聯合會（CNBPF）明講「可頌的形狀沒有任何規定」。他們的手工
維也納麵包規範裡，彎的和直的都算可頌，而且那份規範**根本沒提瑪琪琳**，只講奶油。但消費者到現在
還是照這個規則在買。

對照布里歐：布里歐是**假故事**（瑪麗·安東妮那句話），可頌是**假法規**。兩張卡合起來說明一件
事：麵包的名字常常由「大家以為的規則」定義，而不是真的規則——第七種命名來源，而且是被拆穿的那種。

## L2 座標

**`classicBreads.ts` 目前沒有可頌這一筆**——以下座標是從查證來源反推的，不是從現有程式碼抄來的。

| 軸 | 程度 | 範圍 | 註解 |
|---|---|---|---|
| 含水量 | #含水量/中低 | `48–58` | détrempe（基本麵團）本身要偏乾，才擀得動 |
| 豐富度 | #豐富度/極高 | `85–100` | 裹入奶油佔麵粉重 45–55%（專業配方 50–80%）。爆表 |
| 麥種結構 | #麥種/高 | `90–100` | 白麵粉 |
| 發酵時間 | #發酵/中低 | `20–40` | 通常隔夜冷藏發酵，但不是酸種等級 |
| 麵筋擴展 | #麵筋/高 | `75–90` | 這格是這張卡的核心，見 L4 |

## L4 勾稽

```
#豐富度/極高 + 層壓 -- 油是冷的整塊夾在層間，油膜碰不到麵筋蛋白 -- #麵筋/高
              （所以「油 shorten 麵筋」不是必然發生，是有前提的：油得先混進麵團才會發生）

層壓 -- 奶油裡的水分在烤箱裡變成蒸氣，把麵團一層層撐開 -- 層次與酥
              （撐得開的前提是麵筋要夠強，所以可頌反而需要高筋麵粉）

層壓 -- 溫度一升，奶油融進麵團，層就沒了，變成一般的甜麵包 -- 全程低溫
              ※ 這是代價邊，不是因果邊：可頌付的是溫度控制這種代價，
                跟免揉付時間、巧巴達付手感，是三種不同的貨幣

可頌 -- 奶油量比你還多，麵筋卻更高：差別不在多少，在有沒有混進麵團裡 -- 布里歐
```

> ⚠️ **這張卡打破了布里歐那條邊，但不是因為那條邊寫錯了。**
> 布里歐卡片寫「油 shorten 麵筋」，可頌的奶油量比布里歐還多，麵筋卻更高。差別不在「多少」，
> 在「油放在哪裡」：布里歐的油混進麵團裡，可頌的油整塊夾在層間，麵筋壓根碰不到它。布里歐那條
> 邊沒有錯——它只是漏寫了一個前提：**這條規則要成立，油得先混進麵團。** 現在的邊沒有地方放
> 「這條邊在什麼條件下才成立」，可頌把這個洞逼出來了。

## L3 結果

蜂窩狀的層次斷面、外酥內軟、奶油香、很快就軟掉——酥脆撐不過幾小時。
