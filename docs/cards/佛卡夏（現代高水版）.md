# 佛卡夏（現代高水版） Modern High-Hydration Focaccia

`BV-009` · #family/佛卡夏 · 一盤油泡出來的氣孔，手只負責折疊，剩下交給水和時間

## L1 命名

「focaccia」來自拉丁文 *panis focacius*，字根 *focus* ＝爐床，意思是「在爐床（爐灰）上烤的
扁麵包」。這個字以拉丁形態最早見於 14 世紀文獻。

**現代高水版不是一款有古老名字的麵包**，是近代家庭烘焙把「免揉＋高含水＋長時間發酵」這套手法
套進佛卡夏的結果。它的來歷不是傳說，是查得到的近二十年出版品——見 L4。

## L2 座標

範圍寬度 ＝ 模糊空間。

| 軸 | 程度 | 範圍 | 註解 |
|---|---|---|---|
| 含水量 | #含水量/高 | `75–95` | 定義軸。同一套做法水越加越多：Samin 74%、King Arthur 79%、Bon Appétit ~95% |
| 豐富度 | #豐富度/低 | `15–25` | 這格只算**麵團裡**的油（Samin 7%、KA 5%、BA 9%）。真正的油在盤底和表面，這格看不到——見 L4 |
| 麥種 | #麥種/高 | `85–95` | 白色中筋或高筋，全穀比例低或零 |
| 發酵 | #發酵/中高 | `45–70` | 冷藏隔夜 8–24 小時（Samin 室溫 12–14 小時）。真值以小時計，見 issue #16 |
| 麵筋 | #麵筋/中 | `55–70` | 不揉，靠盆內折疊＋時間長出來。模型的 `KNEAD_SCORE` 會把它壓到 10（見 issue #17） |

## L4 因果／前提

```
BV-009 -- 同宗、不同做法：現代高水版＝把免揉高水手法套進佛卡夏。技術源頭是 2006 年
          Jim Lahey／Mark Bittman 在《紐約時報》定型的免揉法，2017–2020 由 Samin Nosrat
          與 Bon Appétit 帶進家庭烘焙圈 -- BV-008 佛卡夏（熱那亞）
          ※ 前提邊，hard。技術查證見來源；「普及」一說屬可能

高含水 + 時間 -- 水多到麵團無法成塊，發酵拖夠久讓麵筋自行排列，所以不必揉 -- 麵筋

麵筋 -- 不揉，靠盆內數次拉折加長時間鬆弛 -- 折疊 + 時間

油 + 盤底 + 表面 -- 油集中在烤盤與表層、不進麵團核心，所以底部近乎油煎、指洞積油 -- 底部油脆
              ※ 豐富度那格只記油量、不記油在哪裡，這條邊接不進 #豐富度（見 issue #36）
```

## L3 結果

底部因盤底積油而近乎油煎，脆、帶焦香；內裡是高含水撐出來的大而不規則氣孔，柔軟濕潤。表面按出的
指洞積住橄欖油與（若有）鹽水，出爐後洞裡是油亮的鹹點。整體是「外層油脆、內層氣孔多而濕」的對比。

## L5 手

```
! 混合後 0 分鐘：只把材料拌成一團無法成形的濕麵糊，不要想揉——這個含水量揉不動也不該揉
! 前 2 小時內：每隔約 30 分鐘做一次盆內折疊（拉起一邊蓋過中央），共約 3–4 次，建立麵筋
! 折疊後 8–24 小時：加蓋冷藏隔夜，是風味與氣孔的主要來源，不要省
! 入盤前：盤底先鋪厚油，麵團倒上後只做延展、不重新塑形，保住已生成的氣體
! 烤前 0 分鐘：指尖以傾斜角度按穿麵團到見盤底，按出洞後淋油（Samin 版另淋鹽水）
! 出爐後 0 分鐘：立刻脫盤移到網架，底部才不會被盤內餘油與蒸氣悶軟
```
