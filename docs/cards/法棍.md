# 法棍 Baguette

`BV-001` · France · pain de tradition française

## L1 命名 #命名/法律

1993《Décret Pain》：只准麵粉、水、鹽、酵母。不准冷凍、不准添加物、不准防腐劑，必須在賣的店裡做完。

**它的模糊空間是被立法切掉的。** 別的麵包靠習慣定義，它靠法條。

## L2 座標

範圍寬度 ＝ 模糊空間。窄 ＝ 動一下就不是它了。

| 軸 | 程度 | 範圍 | 註解 |
|---|---|---|---|
| 含水量 | #含水量/中高 | `65–75` | 實際烘焙百分比。甜蜜點 68–70，你填的 68 正中紅心 |
| 豐富度 | #豐富度/零 | `0–3` | **寬度≈0**。法律釘死的一根桿 |
| 麥種結構 | #麥種/高 | `90–100` | 白麵粉 |
| 發酵時間 | #發酵/中 | `35–60` | 寬，因為直接法／poolish／隔夜冷藏都算法棍 |
| 麵筋擴展 | #麵筋/高 | `80–95` | |

## L4 勾稽

```
#豐富度/零 -- 沒有油膜，麵筋不被 shorten -- #麵筋/高
              （省力達成：不用跟油打架）

#豐富度/零 -- 沒有油鎖水 -- 老化快，24 小時就不行
              （法令不准防腐劑也不准冷凍 → 這條路被封死）

#含水量/中高 -- 麵團夠鬆，氣孔撐得開 -- 不規則大氣孔

#豐富度/零 + #糖/無 -- 沒有上色來源 -- 靠高溫 + 蒸氣 + 長發酵的殘糖
              （Hamelman：5% 以下幾乎不上色 → 它的色是「省」出來的）
```

## L3 結果

薄脆殼、不規則大氣孔、嚼感。麥香當主角，因為沒別的味道遮它。**24 小時後結束。**
