# 潘娜朵尼 Panettone

`BV-003` · Milano · 住在空洞裡的星

## L1 命名

**名字的意思就是「大麵包」。** 米蘭方言 `pan`（麵包）＋增大詞尾 `-on` = `panaton`。
1606 年的米蘭方言字典就收了這個詞，解釋是「聖誕節做的大麵包」。

1814 年的字典第一次寫下它長什麼樣：**「用奶油、糖和葡萄乾（`ughett`）裝點的一種麵包，
我們城裡在聖誕做各種形狀。」** ｜`確證`

**特色**：發酵要好幾天。裡頭是橘子乾、葡萄乾、檸檬皮這類乾燥蜜餞。常溫放得住，一週以上，
有的到二十天；買回來先放三四天再吃最好。切片直接吃，配甜飲或葡萄酒，義大利有些地方
配馬斯卡彭鮮奶油。

**法規**：義大利法規定要叫 panettone 就**必須用天然酵種** -- L4

## L2 座標

| 軸 | 程度 | 範圍 | 註解 |
|---|---|---|---|
| 含水量 | #含水量/中 | `55–65` | 數字騙人——水幾乎全是蛋黃和奶油帶進來的 |
| 豐富度 | #豐富度/極高 | `85–95` | 實作約 **30% 奶油 + 40% 糖 + 43% 蛋黃**（對總粉重） |
| 麥種結構 | #麥種/極高 | `95–100` | 特高筋。扛得住大量奶油，又要撐得起長發酵 |
| 發酵時間 | #發酵/爆表 | `72–120 小時` | **直接寫小時，不換算成 0–100 分**（見 issue #16） |
| 麵筋擴展 | #麵筋/滿 | `100` | |

## L4 勾稽

```
#豐富度/極高 + #發酵/極高 -- 油包住澱粉，酵母沒糖可吃
                             ＋糖用滲透壓把酵母的水抽走 -- 空洞
                             （一次給太多糖會直接殺死酵母）
```

**因為**又油又甜的麵團會同時餓死酵母、又抽乾酵母，**所以** panettone 沒辦法只靠配方解決，
它得付出下面這一整串代價，才有辦法讓這種麵團還發得起來：

```
-- 天然酵種（pasta madre）：每天餵，一條種養好幾年甚至跨代
-- 耐糖酵母：長期餵糖篩選出來的菌株（或 SAF Gold）
-- 特高筋麵粉：扛得住大量奶油又撐得起長發酵
-- 兩段麵團（primo/secondo）＋中間長發酵：分批給糖，讓酵母先繁殖夠
-- 溫度和 pH 全程精準控制
```

## L3 結果

絲狀撕裂、滿口奶油和蛋黃香、放得久（油鎖水）。

**入口極輕**——注意這裡的「輕」講的是**密度，不是重量**。一顆 panettone 常常重達 1 公斤，
但它同時發得非常大（接近一顆小籃球），所以每一口的組織其實鬆到幾乎沒有抵抗。
**同樣 1 公斤，白吐司是紮實一條，它是一個圓頂。**

**代價**：**發酵**至少 3 天；而且開工之前，lievito madre 本身要先養好。

## L5 手

```
! 長期（以年計）：lievito madre 每天餵。「每天」是餵的頻率，「好幾年」是這條種的壽命
                  —— 這不是步驟，是一種生活方式
! 開工前（約 1 天）：3 次預備續種，把種的力量拉到最強
! 全程：溫度 + pH 控制
! 出爐後 0 分鐘：立刻用長籤穿過底部 2 cm 處
! 出爐後數小時：倒吊到完全放涼才能翻正
  ↑ 慢一步就會被自己的重量壓垮，「像舒芙蕾一樣塌掉」
```
