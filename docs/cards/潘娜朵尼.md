# 潘娜朵尼 Panettone

`BV-003` · Milano · 住在空洞裡的星

## L1 命名 #命名/法律 #命名/故事

**它兩種都有。這張卡把前兩張合起來了。**

**法律**：義大利 2005/07/22 部長令（2017 修）。要叫 panettone：奶油 ≥16%、蛋黃 ≥4%、葡萄乾＋糖漬果皮 ≥20%，**而且必須用 lievito madre**——商業酵母做的不准叫這個名字。

**故事**：Ludovico il Moro 的廚房小弟 Toni，聖誕夜主廚烤焦了甜點，他拿自己私藏的酵種救場，做出「Pan de Toni」。**這是假的。** 這類傳說全是 19 世紀末到 20 世紀初編的，而且把發明時間放在一個「根本還不存在類似東西」的年代。

**真的那個**：Angelo Motta，1919 年米蘭。1920 年代他接了幫米蘭俄僑做 kulich 的活，於是把 panettone 加更多油脂，還用草紙裹起來讓它長高——**現代 panettone 那個蘑菇頭是 1919 年的工業發明，抄的是俄國麵包。**

> 法棍靠法律、布里歐靠故事，它兩個都要。而且它的「傳統」比傳說年輕，還是外國來的。

## L4 勾稽

```
#豐富度/極高 + #發酵/極高 -- 油包澱粉斷糖源，糖又用滲透壓抽乾酵母 -- 空洞
                             （一次給太多糖會直接殺死酵母）

     ↑ 布里歐選擇投降：把 #發酵 降到 20，繞過去
     ↑ Panettone 選擇不投降，於是要付這些代價 ↓

-- pasta madre：每天餵、養好幾年甚至跨代、開工前還要 3 次預備續種
-- 耐糖酵母：長期餵糖篩選出來的菌株（或 SAF Gold）
-- 特高筋麵粉：扛得住大量奶油又撐得起長發酵
-- 兩段麵團（primo/secondo）＋中間長發酵：分批給糖，讓酵母先繁殖夠
-- 溫度和 pH 全程精準控制
```

**同一個 richness，兩種答案。布里歐 90/20，Panettone 90/100。**
差別不在配方，在「要不要跟物理談判」。

## L3 結果

絲狀撕裂、極輕、滿口奶油和蛋黃香、放得久（油鎖水）。

**代價**：至少 3 天，而且 lievito madre 要先養好幾天。

! lievito madre 要每天餵，養好幾年 —— 這不是步驟，是一種生活方式

## 你的濾鏡

#豐富度/極高，奶油＋蛋黃＋糖全滿。在你的濾鏡下它**暗到底**。

但它是你會想繞過去看一眼的那種暗星——不是因為想吃，是因為想知道有人怎麼把星星種在空洞裡。

## 這張卡推翻了一件事

你說「容錯高的麵包可能會有更大的模糊空間」。**Panettone 是反例，而且是乾淨的反例。**

- **法律給的模糊空間很鬆**：奶油 ≥16%、蛋黃 ≥4% 是**下限，不是區間**，往上愛加多少都行
- **物理給的模糊空間≈0**：溫度、pH、加糖時機、倒吊時機，錯一步就是磚頭

**所以「模糊空間」和「容錯」是兩個獨立的東西**，而法棍跟 panettone 剛好是對角線上的兩個證明：

|  | 法律鬆緊 | 物理鬆緊 |
|---|---|---|
| 法棍 | **緊**（四樣材料，違者不得稱之） | 鬆（難做，但翻車了還是麵包） |
| Panettone | 鬆（只有下限） | **緊**（翻車＝磚頭） |

順帶：**panettone 是「怎麼翻車都能吃」這句話唯一失效的地方。** 這不會讓那句話變錯，只是標出它的邊界在哪。
