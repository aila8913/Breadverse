# 佛卡夏 Focaccia

`BV-008` · Genova, Italy · 爐床上烤出來的名字

## L1 命名 #命名/地理標示

字源是拉丁文 `panis focacius`，「爐床上烤的麵包」，`focus` 就是爐床、壁爐。名字指的是**烤的
地方**，不是配方，也不是形狀——這點跟酸種鄉村同源，都是被生產條件命名的。但今天真正在法律上
定義「佛卡夏」的不是這個字源，是底下這件事。

**關鍵事實**：熱那亞佛卡夏（focaccia genovese，就是大家想的那種厚厚軟軟的）**沒有任何法律
保護**。真正拿到歐盟 IGP 地理標示的是它的冷門表親 **Focaccia di Recco col formaggio**（歐盟
2015/39 號實施條例，2015 年 1 月），而且那是一種**沒發酵、薄如紙夾起司**的東西，跟一般人認知的
佛卡夏幾乎沒關係。IGP 只准在 Recco、Avegno、Sori、Camogli 這四個市鎮做。

對照法棍：法棍的法律管的是**配方**（只准麵粉、水、鹽、酵母）；IGP 管的是**地點**。同樣是「靠
法律」，管的東西完全不一樣。

一句話：**最有名的那個沒人保護，被保護的那個沒人知道。**

## L2 座標

> ⚠️ **`classicBreads.ts` 這一筆現在是錯的。**
> 現值 `hydration: 85`。但傳統熱那亞佛卡夏的含水量是 **55–65%**（Anna Del Conte 65%、
> Marcella Hazan 66.7%）。85% 是現代改編的高水版本，不是傳統款。**差了將近 20 分，這顆星會被
> 畫到宇宙裡完全錯誤的位置。**

| 軸 | 程度 | 範圍 | 註解 |
|---|---|---|---|
| 含水量 | #含水量/中 | `55–70` | 傳統 55–65；現代高水版可到 80+，範圍給寬一點但重心往下拉 |
| 豐富度 | #豐富度/低 | `15–30` | 橄欖油。麵團裡約 5–10%，**表面另外再淋一層** |
| 麥種結構 | #麥種/高 | `85–95` | 白麵粉 |
| 發酵時間 | #發酵/中 | `35–55` | |
| 麵筋擴展 | #麵筋/中高 | `50–70` | |

## L4 勾稽

```
揉進麵團的油 -- 油膜包住麵筋蛋白 -- #麵筋/中高
              ※ 這條是往下壓的：佛卡夏的麵筋不高，是這 5–10% 的油付的帳

表面淋的油 -- 從頭到尾沒碰到麵筋，只留在最外層 -- 殼薄而軟不脆
表面淋的油 -- 積在指印凹洞裡，烤完留在表面 -- 表面油亮

佛卡夏 -- 油在表面，只改殼；可頌的油在層間，只撐層；差別不在油多少，在油放哪裡 -- 可頌
佛卡夏 -- 油在表面碰不到麵筋，布里歐的油混進麵團裡直接壓麵筋 -- 布里歐
```

> ⚠️ **三張卡撞在一起才看得出來的洞：豐富度軸只記「油有多少」，不記「油在哪裡」。**
> 布里歐把油混進麵團、可頌把油整塊夾在層間、佛卡夏把油淋在表面——三種位置對麵筋的後果完全
> 不同，但三者的豐富度數值分不出這件事。
>
> 注意這張卡的 L4：**`#豐富度/低` 一條邊都拉不出去。** 它得先拆成「揉進麵團的油」和「表面淋
> 的油」兩個端點，邊才接得上——因為這兩者的後果是相反的。**軸值本身當不了因，這是軸壞掉的
> 徵狀，不是寫法問題。**

## L3 結果

表面油亮、指印凹洞裡積油、殼薄而軟不脆、鹹、內部氣孔中等、橄欖油香當主角。

## L5 手

```
! 戳指印的深度和時機
! 油要捨得下
! 發酵完不能壓
```

## 你的濾鏡

#豐富度/低 半亮——比法棍暗一點，但比可頌亮很多。發酵時間普通，沒有加分也沒有扣分，這顆星是
中間偏亮的位置。
