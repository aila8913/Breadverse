# 免揉麵包 No-Knead Bread

`BV-005` · New York · 一個被拿掉的步驟

## L1 命名 #命名/媒體

2006 年，Jim Lahey（紐約 Sullivan Street Bakery）的做法，被《紐約時報》專欄作家 Mark Bittman
寫成一篇專欄。文章一登，全球家庭烘焙跟著炸開。

**這是唯一一個以「不做什麼」命名的麵包。** 別的麵包用產地、法規、故事命名，它用一個被省略的動作
命名。而且它不是一個新麵包，是一個舊麵包 + 一個被拿掉的步驟。

## L2 座標

範圍寬度 ＝ 模糊空間。

| 軸 | 程度 | 範圍 | 註解 |
|---|---|---|---|
| 含水量 | #含水量/高 | `70–80` | Lahey 原始配方約 75% |
| 豐富度 | #豐富度/零 | `0–3` | 麵粉水鹽酵母，跟法棍同組 |
| 麥種結構 | #麥種/高 | `85–100` | |
| 發酵時間 | #發酵/中高 | `50–65` | 室溫 12–18 小時，Lahey 自己偏好 18 |
| 麵筋擴展 | #麵筋/中高 | `60–70` | ⚠️ 你的公式會給它 10。這格是這張卡的核心，見下 |

> ⚠️ **它撞破了同一根軸，方向跟巧巴達一樣。**
> `KNEAD_SCORE["no-knead"] = 10`。但免揉麵包的麵筋是**真的有發展**的：麥穀蛋白與醇溶蛋白吸水
> 之後會自己連結，不需要機械外力；蛋白酶（protease）分解蛋白質讓麵團更延展，澱粉酶（amylase）
> 把澱粉轉成糖。12–20 小時之後，麵筋網絡在完全沒被碰過的情況下已經建立起來。成品的麵筋水準
> 大約是 60–70，不是 10。
>
> **所以這條軸量的是「你花了多少力氣」，不是「麵筋到底擴展了多少」。** 免揉麵包用時間買到了
> 別人用手買的東西，而軸只看得到手。跟巧巴達是同一個洞（issue #17）。

## L4 勾稽

```
#含水量/高 + #發酵/中高 -- 蛋白質吸水後自己連結，不需要機械外力 -- #麵筋/中高
              （麵筋不是揉出來的，是水跟時間長出來的）

#發酵/極高 -- 澱粉酶把澱粉轉成糖 -- 風味
              （2 小時室溫發酵做不出來的複雜度）

免揉 -- 麵筋的代價從「技術」換成「時間」 -- 12–18 小時
              （代價邊，不是因果邊）

免揉麵包 -- 同樣靠時間而不是手做麵筋 -- 巧巴達
```

（誠實補一句：Modernist Bread 團隊實測，autolyse 在家庭烘焙的效益其實很小，用全麥粉時甚至有
反效果。長時間靜置不等於自動有效——這條列進來是因為它是查到的反面證據，不是為了唱衰這張卡。）

這正是 issue #22 要的東西的乾淨實例：**免揉麵包是時間貴、技術便宜；法棍反過來，技術貴、時間便宜。**
兩者的「難度」若壓成一顆星等，就分不出來了。

## L3 結果

氣孔開放、殼脆（鑄鐵鍋加蓋模擬蒸氣）、風味比快速發酵深得多。

## L5 手

```
! 幾乎沒有手感門檻 —— 這是它存在的理由
! 唯一需要判斷的是：麵團發好了沒
! 鑄鐵鍋要先預熱到很燙，這是器材門檻，不是手感門檻（見 issue #18）
```

這張卡的 `!` 特別少，而且那正是重點。

## 你的濾鏡

#豐富度/零 亮、#發酵/極高 亮。**在你的濾鏡下這是一顆很亮的星，而且是亮星裡最便宜的那顆。**
