# 飲食起源查證

## 這個 skill 在解什麼問題

飲食史是**假資訊密度最高的領域之一**。原因不是有人惡意造假，是三股力量長期疊加：

1. **民族／地方榮譽**：每個地方都想證明某樣東西是自己先做的。
2. **行銷**：20 世紀食品工業要把地方食物賣到全國，需要一個能講的來歷。
3. **回音**：一個說法被抄一百次，看起來就像一百個來源。

結果是網路上關於任何一款名麵包的「由來」，**預設應該當成未查證**，不論它出現在多少地方、
講得多具體。具體本身就是警訊——傳說會隨時間長出細節（人名、年份、公爵是誰），
真的紀錄反而通常很乾（一本字典裡的一個詞條）。

Breadverse 的卡片是要餵給圖的資料。**一條假的來歷會變成圖上一條真的邊**，所以 L1 不是裝飾層，
它跟含水量一樣需要查證。

## 立場

> **判準不是「多少人這樣說」，是「最早的證據長什麼樣、什麼年代、誰寫的」。**

一個說法只有兩種東西能救它：**同時代的文獻**，或**技術上的可能性**。兩個都沒有就是傳說。

## 證據層級

由上而下，上面的直接推翻下面的：

| 層級 | 是什麼 | 效力 |
|---|---|---|
| **A. 同時代一手文獻** | 方言字典詞條、行會／稅務紀錄、食譜手稿、報紙廣告、商標與專利登記、法規原文 | 決定性。**這是唯一能定年的東西** |
| **B. 學術飲食史** | 食物史學者的專著與期刊論文（他們會標最早出處） | 高。可直接引用其定年 |
| **C. 官方／公會明文** | 法規、業界公會聲明、保護標章規範 | **只對「現在的規則」有效力，對歷史沒有** |
| **D. 百科、報導** | 維基百科、報紙專題 | 零效力，只當**索引**用——去追它的引註 |
| **E. 食譜部落格、品牌官網、觀光局頁面** | | **零效力**。品牌官網講自家產品的由來＝行銷文案，不是史料 |

⚠️ **最常見的錯誤是拿 C 當 A。** 公會說「我們的可頌規範沒有形狀規定」——這對「今天有沒有規定」
是決定性的，對「19 世紀有沒有」什麼都沒說。

## 六種標準失效模式

查任何起源說法，逐條過一遍。**打中任何一條，該說法降級。**

### H1 俗詞源（folk etymology）
名字聽起來像人名或某句話 → 有人倒推出一個故事。

**測試：這個詞在當地方言／語言裡有沒有平凡的構詞解釋？** 有的話，人名版本幾乎必假。

> `panettone` = 米蘭方言 `panaton`（`pan` + 增大詞尾 `-one`）＝ **大麵包**。
> 「Pan de Toni（Toni 的麵包）」是先有詞、後有人，不是先有人、後有詞。

### H2 被發明的傳統（invented tradition）
19 世紀末到 20 世紀的地方／民族認同工程，會回頭給食物補一個古老出身。

**測試：最早文獻年代 vs 說法宣稱的年代，差幾百年？** 差距越大越可疑。

### H3 行銷神話
說法第一次出現的時間，剛好等於某家公司要把它賣到全國的時間。

**測試：把「故事最早出現年份」和「工業化／品牌化年份」畫在同一條線上。** 重疊就是它。

### H4 時代錯置（這條最有力）
故事宣稱的年代，**還不存在做出這個東西所需的原料或技術**。

這條之所以最好用，是因為它跟這個專案判斷詞彙的方式一樣：**看機制，不看說法**。
一個說法可以沒有反證，但只要它需要一個當時不存在的東西，它就是死的。

**技術年代閘門（粗略，引用時標「約」）：**

| 閘門 | 大約年代 | 之前不可能有 |
|---|---|---|
| 哥倫布交換 | 1492 後 | 玉米、番茄、馬鈴薯、可可、香草 |
| 平價砂糖 | 甜菜糖 1801 起，拿破崙封鎖期擴散 | 在此之前糖是奢侈品，甜麵包＝貴族／節慶品 |
| 化學膨脹劑 | 約 1840–50 年代 | 泡打粉類產品 |
| 工業純種酵母 | 約 1860 年代起 | 只能用天然酵種、酒廠酵母（barm） |
| 滾筒磨粉 | 約 1870–80 年代普及 | **便宜的白麵粉**。此前白麵粉＝有錢人 |
| 人造奶油 | 1869 | 相關的油脂替代敘事 |
| 家用冷藏 | 約 1920–30 年代 | 低溫發酵、冷藏鬆弛、冷奶油裹入的家庭版 |
| 烤箱恆溫控制 | 約 1920 年代起 | 任何依賴精確爐溫的故事 |

### H5 單一來源迴音
五十個網頁講同一件事，可能只是同一個來源被抄五十次。

**測試：往回追到最早那一次出現。** 追不到就標「流傳但無據」，不要因為看到很多次就升級。

### H6 真習俗被假起源綁架
**這條是最容易誤殺的。** 起源故事是假的，**不代表那個食物與該場合的關聯是假的**。

> 潘娜朵尼的 Toni 廚房小弟故事是假的（H1 直接打死）。
> 但「米蘭在聖誕節吃一種大的甜麵包」有老得多的痕跡——1606 年的米蘭方言字典就收了
> `panaton`，解釋成聖誕節做的大麵包。
> **三個傳說的功能是事後替一個早就存在的習俗補一個來歷**，不是它的起因。

處理方式：**分開寫兩件事**——「這個說法（假）」和「底下那個真的東西（真，有文獻）」。
只寫「這是假的」就把真的那半也一起丟掉了。

## 產出：每條主張帶一個信心等級

L1 的每一句歷史主張都要落到四級之一，**並附最早證據**：

| 等級 | 意思 | 寫法要求 |
|---|---|---|
| `確證` | 有 A 或 B 級來源，且能定年 | 必須寫出最早出處與年份 |
| `可能` | 有間接證據、技術上可行，但沒有直接文獻 | 寫明缺的是什麼 |
| `流傳但無據` | 廣為流傳，追不到源頭，但也沒有反證 | **不要寫成「據說」就算了**，要標明追到哪裡斷掉 |
| `已否證` | 有明確反證（H1／H4 打中，或權威機構明文否認） | 必須寫出否證的依據，不只是「這是假的」 |

這對應 issue #24 的 `source` / `confidence`。**L1 是這兩個欄位最先需要落地的地方**——
座標數字至少還有食譜可查，歷史主張沒有這一層就只是傳話。

## 三條操作紀律

1. **先查最早出處，再讀故事。** 順序反過來的話，會先被故事說服，然後只去找支持它的東西。
2. **否證了要說明否證的依據**，不要只寫「這是假的」。「假的」是結論，卡片要放的是**理由**——
   理由才可能被下一張卡推翻，結論不行。
3. **不要為了讓卡片好看而保留一個已否證的故事當「氣氛」。** 要留就標成 `已否證` 並寫出否證依據；
   已否證的傳說本身是有價值的資料（誰在什麼時候需要這個故事），但它必須被標記成那樣。
